# gijutsu-lab

中学校技術科の授業で使う、ブラウザだけで開ける学習教材（HTML）をまとめて公開するためのリポジトリです。
生徒はアカウント登録やアプリのインストールなしで、URLを開くだけで教材を使えます。

## 公開URL

GitHub Pages で公開しています。

- トップページ（単元一覧）: `https://<ユーザー名>.github.io/gijutsu-lab/`
- 各単元: `https://<ユーザー名>.github.io/gijutsu-lab/<単元フォルダ名>/`

## フォルダ構成

```
gijutsu-lab/
├── index.html          … 単元一覧のトップページ
├── README.md            … このファイル
├── gear-ratio/           … 単元「回転運動を伝える仕組み」
│   └── index.html
└── <新しい単元フォルダ>/
    └── index.html
```

## 設計方針

- **1単元＝1つのHTMLファイルで完結**させる。外部サーバーやビルド処理、共通JS/CSSファイルへの分割は行わない。
  多少コードが重複しても、担当者が変わったときに「そのフォルダの中だけ見ればすべて分かる」状態を優先している。
- 各HTMLファイルの冒頭に、保守担当者向けのコメント（ファイル構成・データを追加/編集する場所）を書く。
- 生徒の学習データ（クイズの結果など）はサーバーに送信せず、生徒自身の端末にJSONファイルとしてダウンロードさせる方式にする（個人情報をリポジトリやサーバーに残さないため）。

## 新しい単元を追加する手順

1. リポジトリ直下に、単元名のフォルダを作る（フォルダ名はローマ字のスラッグ。例: `electricity-basics`）。
2. そのフォルダの中に `index.html` として教材を1ファイルで作成する。
3. リポジトリ直下の `index.html` を開き、`UNITS` 配列に以下の形式で1件追記する。

   ```js
   {
     slug: 'electricity-basics',              // フォルダ名と一致させる
     title: '電気の利用と安全',                 // カードに表示するタイトル
     desc: '一文程度の説明。何を学ぶ教材か。',
     tags: ['エネルギー変換の技術']              // 任意。関連する内容領域など
   }
   ```

4. GitHubにコミットして数分待てば、トップページに新しいカードが自動で表示される。

## 更新履歴の残し方

内容を修正する際は、`index.html` を直接編集して commit するだけでよい（ビルドや再デプロイの操作は不要）。
何を・なぜ直したかは commit メッセージに一言残しておくと、後から見返すときや他の担当者が引き継ぐときに役立つ。
